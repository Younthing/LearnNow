上一页把网和用法拆开了。这一页用「小记」把边界钉死：什么时候你在用 Web，什么时候只是在用网。

你在浏览器里打开 `notes.example.com`、点开某条留言的链接——这是典型的 Web。你用另一款 app 直接把留言同步到手机，界面里没有网页、也没有链接跳转——那通常走的是网上的其他约定，不算 Web。

## 用不用浏览器，是条实用分界

日常里可以靠一个粗筛子：

| 你在做什么 | 更像 |
| --- | --- |
| 浏览器里点链接看页面 | Web |
| 专用 app 直接同步数据 | 互联网上的其他用法 |
| 两者都要传数据 | 都依赖互联网 |

粗筛子会漏掉边界情况，但对零基础入门够用：先分清「通路」和「打开网页这一路」。

## 为什么这门课从 Web 讲起

「怎样构建可以通过浏览器使用的应用」问的正是 Web 这一路：页面怎么写、样式怎么加、交互怎么做、服务器怎么回、数据怎么存。

互联网的其他用法后面可以单独学。本课只把分界线立住，后面所有单元都默认：用户从浏览器走进来。

```text
本课范围
├─ 会分：互联网 ≠ Web
├─ 会认：浏览器打开链接页面
└─ 延后：邮件、文件传输等其他用法
```

## 本课在整门课中的位置

后面单元都默认用户从浏览器走进来：先写页面结构，再外观与行为，再服务器与数据库。互联网的其他用法（邮件等）不在本课展开。
