## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | CSV 和 JSON 文件是什么？ |
| **心智模型** | CSV 用表格行列存数据；JSON 用嵌套的键值/列表表达结构。 |
| **学习者起点** | 会读写文本。课内建立：CSV、JSON、各自形状。 |
| **终点行为** | 1. 能认出 CSV 行列。2. 能认出 JSON 对象/数组。3. 能判断表格用 CSV、嵌套结构用 JSON。 |
| **概念预算** | 核心：两种结构化文本。支撑：逗号分隔、键值花括号。识别：csv/json 模块。延后：API 细节。 |
| **贯穿例子** | 科目分钟表 vs {"语文":40,...}。 |
| **范围边界** | 会讲：是什么与何时用。不讲：完整库 API。 |

## 讲义

纯文本可以任意格式。社区约定了两种常见结构：CSV 像表格；JSON 像嵌套的字典/列表。

选格式时看数据形状：整齐行列 → CSV；层层字段 → JSON。
