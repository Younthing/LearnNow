分工立住了。还容易混的一点是：你手机很强，为什么还要服务器？

因为留言要给很多人看，也要在换设备后还在。浏览器关掉可以清掉临时副本；大家共享的那份「真数据」，需要放在一直在线、能应答请求的那一端。

## 浏览器能做的，和做不了的

浏览器擅长：发请求、渲染页面、在你本机做一些即时计算。它不适合当所有人的共享仓库——你的手机关机了，别人还要能打开「小记」。

```text
浏览器这边
├─ 要页面、画页面
└─ 本机临时状态

服务器那边
├─ 一直听请求
└─ 保管可共享的内容
```

## 边界：本课不讲服务器内部

服务器里面可能跑着许多程序、连着数据库。那些是后面单元的事。现在只要能指着一次打开说：哪一步是浏览器在要，哪一步是服务器在给。
