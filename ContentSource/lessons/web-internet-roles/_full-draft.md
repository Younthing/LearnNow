## Brief

| 项 | 内容 |
|----|------|
| **核心问题** | 浏览器和服务器分别做什么？ |
| **心智模型** | 一端要和画（浏览器），一端听和给（服务器）；共享内容放远端。 |
| **学习者起点** | 已分清互联网与 Web。 |
| **终点行为** | 1. 能指出一次打开中两端各自的动作。2. 能解释换设备仍能看见内容为何依赖服务器。 |
| **概念预算** | 核心：两端分工。支撑：请求/应答角色、共享存放。识别：网站口语。延后：HTTP 报文、DNS、路由。 |
| **贯穿例子** | 打开「小记」看留言列表。 |
| **范围边界** | 会讲：分工与为何需要远端。不讲：HTTP 字段、服务器框架。 |

## 讲义

打开小记时，留言通常不在手机里预装。浏览器在你这边要页面、画页面；服务器在远端听请求、给出内容。两端缺一不可。口语「上网站」其实是两端配合。浏览器不能当所有人的共享仓库——关机后别人还要用，所以共享数据放一直在线的服务器。本课不拆服务器内部。
