# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 怎样阅读错误信息？ |
| **心智模型** | 先看最后的异常类型与说明，再看指向的文件与行号，必要时向上追调用链。 |
| **学习者起点** | 知道有运行错误。课内建立：traceback 阅读顺序。 |
| **终点行为** | 1. 能定位最后一行异常名。2. 能找到行号。3. 能说明上面是调用路径。 |
| **概念预算** | 核心：阅读顺序。支撑：异常类型、行号、调用链。识别：堆栈帧。延后：pdb。 |
| **贯穿例子** | int 转换失败的 traceback。 |
| **范围边界** | 会讲：怎么读。不讲：如何设计异常类。 |

## 讲义

红字一大片时别从头逐字念。先跳到最后：什么异常、什么说明；再看它指出的行；需要时再往上看是谁调用过来的。
