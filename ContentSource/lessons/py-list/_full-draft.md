## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 列表适合保存什么数据？ |
| **心智模型** | 列表是有序、可变的一串位置；用下标取、可增删改。 |
| **学习者起点** | 会变量。课内建立：列表、下标、可变。 |
| **终点行为** | 1. 能判断同类多项用列表。2. 能用下标取值。3. 能说明列表可改。 |
| **概念预算** | 核心：有序可变序列。支撑：下标从 0、追加、修改。识别：len。延后：切片细节。 |
| **贯穿例子** | 一周学习分钟列表。 |
| **范围边界** | 会讲：适合场景与基本操作。不讲：列表推导、高级切片。 |

## 讲义

多天分钟若用 minutes1、minutes2…会爆炸。

列表把多项按顺序放在一起：可按下标取，也可追加、修改。适合「一串同类、可能变化」的数据。
