# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 变量的作用范围是什么？ |
| **心智模型** | 函数内赋值的名字默认只在函数内可见；外面同名不一定是同一个。 |
| **学习者起点** | 会参数与返回。课内建立：局部变量、可见范围。 |
| **终点行为** | 1. 能判断函数内变量外面不能直接用。2. 能说明参数也是局部的。3. 能避免靠同名「碰巧共用」。 |
| **概念预算** | 核心：可见范围。支撑：局部、函数外、参数局部性。识别：global。延后：闭包、nonlocal。 |
| **贯穿例子** | 函数内 total 与函数外 total。 |
| **范围边界** | 会讲：局部默认规则。不讲：global 实战、LEGB 全表。 |

## 讲义

在函数里写了 total = ...，外面 print(total) 却报错或不一样。

因为名字有范围：函数内的标签默认只在函数这间小屋里有效。要把结果交出去，用 return，而不是假设外面能看见里面的名字。

| boundary | 用参数进、返回出，而不是同名碰运气 |
