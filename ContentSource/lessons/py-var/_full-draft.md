# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 变量怎样保存数据？ |
| **心智模型** | 变量名是标签，贴在某个值上；以后用名字取回当前贴着的值。 |
| **学习者起点** | 会 print/input。课内建立：赋值、名字、可覆盖。 |
| **终点行为** | 1. 能用赋值保存 input 的结果。2. 能说明再赋值会换掉标签指向。3. 能判断未赋值就使用会出问题。 |
| **概念预算** | 核心：名是标签。支撑：赋值、覆盖、先存再用。识别：合法名字。延后：作用域、类型细节。 |
| **贯穿例子** | minutes 保存今日学习分钟，稍后 print。 |
| **范围边界** | 会讲：赋值与覆盖。不讲：作用域、常量、类型注解。 |

## 讲义

input 接到「40」之后，怎样在后面的步骤里继续用它？

放进变量：名字像标签，贴在值上。minutes = 40 之后，写 minutes 就是在取当前贴着的值。再写 minutes = 50，标签改贴到 50，旧的 40 不再经由这个名字取到。
