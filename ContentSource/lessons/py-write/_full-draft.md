# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 怎样把结果写入文件？ |
| **心智模型** | 打开写入模式 → 写入字符串 → 关闭；"w" 覆盖，"a" 追加。 |
| **学习者起点** | 会读文件。课内建立：写模式、write、追加。 |
| **终点行为** | 1. 能写入一行记录。2. 能区分覆盖与追加。3. 能说明写入的是文本。 |
| **概念预算** | 核心：写出文本。支撑：w/a、write、换行。识别：writelines。延后：缓冲细节。 |
| **贯穿例子** | 把新的「语文,40」追加到 study.txt。 |
| **范围边界** | 会讲：写与追加。不讲：并发锁、原子替换。 |

## 讲义

程序算完或接收了新记录，要落到磁盘，下次才能读。

用 "w" 写入会覆盖原文件；用 "a" 在末尾追加。写入的是字符串，记得自己加换行。
