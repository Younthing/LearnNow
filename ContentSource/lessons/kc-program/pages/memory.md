CPU 一直在从台面上拿东西。那台面上除了那份清单，还摊着什么？

摊着这次要用的数：旧合计 26、你输入的 12、算出来的 38。清单告诉 CPU 做什么，这些数是它动手的对象。

## 台面上的两类东西

```text
内存（工作台）
├─ 步骤清单：取旧合计 / 取新数字 / 相加 / 交给屏幕
└─ 用到的数：26   12   38
```

CPU 每做一步，都从台面上拿一样东西，再把结果放回台面上。所以这两类东西必须同时摊得开，缺一样这一步就做不下去。

## 谁动手，谁摊东西

CPU 是动手的那一位，内存是摊东西的那块地方。它们的分工可以用三句话分清。

- 谁在改数据：CPU 动手改，内存只是让数据待着。
- 谁在留住数据：数一直待在内存里，CPU 做完一步就不替你留着。
- 数量的意义：内存大，同时摊得开的东西多；CPU 快，每一步花的时间短。

## 台面摊不下的时候

你同时开着地图、音乐和十几个网页，台面就会被占满。机器只能把暂时不用的东西挪走，腾出地方给正在用的。

等你切回记账，它得先把要用的重新搬上来。你看到的那一下卡顿，就是这次重新搬运，不是 CPU 忽然变慢了。

## 那谁在决定挪谁

这一课可以收在一句话上：程序是躺着的清单，运行是 CPU 从台面上逐条取来执行。
