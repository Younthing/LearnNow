@Tip(id: "kc-program-tip-two-numbers", revision: 1, sourcePage: "kc-program-page-cpu", title: "快和多是两件事", systemImage: "cpu", accent: "purple") {
每一步很快，不等于一共很快。一件事久，先问它要做的步数是不是本来就多。
}

@Tip(id: "kc-program-tip-switch-lag", revision: 1, sourcePage: "kc-program-page-memory", title: "切回来卡一下，多半在搬东西", systemImage: "lightbulb", accent: "purple") {
顿一下然后就顺了，通常是刚才被挪走的东西又搬回了内存；如果是一直慢，才该怀疑算力。
}
