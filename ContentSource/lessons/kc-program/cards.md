@Card(id: "kc-program-card-program-vs-run", revision: 1, sourcePage: "kc-program-page-list", topic: "认识计算机", accent: "purple", frontTitle: "程序和运行", frontSubtitle: "点开图标之前和之后", backTitle: "两样东西") {
程序是躺在存储里的一份步骤清单；运行是这份清单被搬上台面、被逐条读掉的那个过程。

@Highlight {
关掉 app 结束的是这一次运行，清单一个字都没少。
}
}

@Card(id: "kc-program-card-step-by-step", revision: 1, sourcePage: "kc-program-page-cpu", topic: "认识计算机", accent: "purple", frontTitle: "CPU 怎么干活", frontSubtitle: "为什么感觉是瞬间", backTitle: "取一条，做一条") {
CPU 一次只做一小步，取一条、执行、再取下一条，顺序照清单写的来。

@Highlight {
快来自小步足够多、足够密，不来自某一步很聪明。
}
}

@Card(id: "kc-program-card-desk-full", revision: 1, sourcePage: "kc-program-page-memory", topic: "认识计算机", accent: "purple", frontTitle: "开太多就卡", frontSubtitle: "顿一下之后又很顺", backTitle: "台面摊不下") {
内存摊着清单和当下要用的数。开的东西太多，暂时不用的会被挪走，切回来得重新搬。

@Highlight {
顿一下然后恢复，指向一次搬运；一直慢，才轮到算力。
}
}
