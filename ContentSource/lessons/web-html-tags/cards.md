@Card(id: "web-html-tags-card-three", revision: 1, sourcePage: "web-html-tags-page-three", topic: "HTML", accent: "mint", frontTitle: "标签元素属性", frontSubtitle: "三个词怎么分", backTitle: "写法 / 整块 / 说明") {
标签是尖括号写法；元素是标签加内容；属性是开始标签上的附加信息。

@Highlight {
排错时指着具体那一层说，比统称「标签坏了」更清楚。
}
}

属性补充地址、类别等；元素基本身份仍由标签名决定。

href 告诉链接去哪，但不代替 a 本身。
}
