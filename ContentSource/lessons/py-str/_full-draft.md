## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 怎样处理字符串？ |
| **心智模型** | 字符串是字符序列；可拼接、切割、去掉首尾空白。 |
| **学习者起点** | 认识 str。课内建立：拼接、split、strip。 |
| **终点行为** | 1. 能拼接提示语。2. 能按分隔符切开。3. 能去掉首尾空白再比较。 |
| **概念预算** | 核心：文本可被加工。支撑：+ / 拼接、split、strip。识别：f-string。延后：正则。 |
| **贯穿例子** | 把「语文,40」切成科目与分钟。 |
| **范围边界** | 会讲：拼接切割清理。不讲：编码细节、正则。 |

## 讲义

文件和输入给的常常是一整段字。要取出科目和分钟，得会切；比较前要去掉空格；提示语要会拼。

字符串不是只能 print，它可以被加工。
