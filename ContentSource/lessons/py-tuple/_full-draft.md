# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 元组和列表有什么区别？ |
| **心智模型** | 元组有序但不可变；列表有序且可变。 |
| **学习者起点** | 会列表。课内建立：元组、不可变、适用场景。 |
| **终点行为** | 1. 能区分可变/不可变。2. 能说明元组适合固定组合。3. 能判断改内容该用列表。 |
| **概念预算** | 核心：不可变有序。支撑：圆括号、不能改元素、固定记录。识别：解包。延后：命名元组。 |
| **贯穿例子** | ("周一", 40) 一天的标签与分钟。 |
| **范围边界** | 会讲：与列表的关键差别。不讲：作字典键的细节深挖。 |

## 讲义

有时你要一对固定信息：星期名 + 分钟，并且不希望被顺手改掉。

元组保持顺序，但创建后不能改元素。要频繁增删改，仍用列表。
