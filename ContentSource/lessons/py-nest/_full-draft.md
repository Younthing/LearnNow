| **心智模型** | 每深一层，要同时记住的「当前在哪条路/哪一轮」就多一层；可读性迅速下降。 |

| **概念预算** | 核心：嵌套增加同时要记的状态。支撑：缩进层次、提前返回/continue、拆函数预告。识别：守卫语句。延后：复杂重构手法。 |
| **贯穿例子** | 一周每天：若分钟>0 再判断是否达标。 |
| **范围边界** | 会讲：为何难、如何减一层。不讲：完整重构目录。 |

## 讲义

循环里再套 if，或 if 里再套循环，常常「能跑但难读」。

因为你要同时记住：现在是第几天，以及是否走进了内层分支。层数一多，大脑的便签纸不够用。对策是减少同时嵌套：提前跳过、拆成函数（下一单元）。
