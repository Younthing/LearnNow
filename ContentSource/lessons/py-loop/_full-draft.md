| 项 | 内容 |
|----|------|
| **核心问题** | 循环怎样处理重复任务？ |
| **心智模型** | 同一套步骤，按次数或按元素自动重复。 |
| **学习者起点** | 会分支。课内建立：for、可迭代序列、循环体。 |
| **终点行为** | 1. 能用 for 打印多天分钟。2. 能区分循环体与重复次数来源。3. 能说明为何不手写五次 print。 |
| **概念预算** | 核心：重复执行同一套步骤。支撑：for、序列、循环体。识别：while。延后：break/continue。 |
| **贯穿例子** | 一周每天学习分钟列表，逐日打印。 |
| **范围边界** | 会讲：for 遍历重复。不讲：嵌套、提前退出。 |

## 讲义

要打印周一到周五每天学了多久。复制五次 print 能用，但改格式要改五处。

循环：准备一串天的数据，用 for 对每一天重复同一套打印步骤。重复的是步骤，变化的是每一次拿到的那个值。
