# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 怎样控制循环的开始和结束？ |
| **心智模型** | while 靠条件决定是否继续；break 提前结束；continue 跳过本轮剩余。 |
| **学习者起点** | 会 for。课内建立：while 条件、break、continue。 |
| **终点行为** | 1. 能写出「输入直到说停」的 while。2. 能说明 break 结束整个循环。3. 能区分 continue 与 break。 |
| **概念预算** | 核心：循环边界可控。支撑：while、break、continue。识别：死循环。延后：else on loop。 |
| **贯穿例子** | 连续录入学习分钟，输入 -1 结束。 |
| **范围边界** | 会讲：while 与提前退出。不讲：生成器、复杂状态机。 |

## 讲义

有时你不知道会录入几天，只知道用户输入 -1 表示结束。for 不太好使。

用 while：条件为真就继续；在循环里读到结束标记就 break。continue 则跳过本轮剩下的话，进入下一轮。
