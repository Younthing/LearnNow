# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 集合怎样处理不重复的数据？ |
| **心智模型** | 集合里每个元素最多一份；适合去重与「在不在」判断。 |
| **学习者起点** | 会列表/字典。课内建立：集合、唯一、成员。 |
| **终点行为** | 1. 能说明集合自动去重。2. 能用 in 判断成员。3. 能判断何时集合优于列表。 |
| **概念预算** | 核心：唯一性。支撑：去重、in、无序认知。识别：交并差。延后：frozenset。 |
| **贯穿例子** | 已学过的科目名集合。 |
| **范围边界** | 会讲：去重与成员。不讲：复杂集合运算深挖。 |

## 讲义

科目名录可能被重复追加「语文」。列表会留下两份；集合只会留一份。

集合保证唯一，并擅长问「有没有」。不保证你习惯的下标顺序。
