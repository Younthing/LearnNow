@Card(id: "kc-files-card-power-line", revision: 1, sourcePage: "kc-files-page-power", topic: "认识计算机", accent: "purple", frontTitle: "断电会丢什么", frontSubtitle: "半句备注没了，合计还在", backTitle: "看它在哪一边") {
内存那块台面上的东西断电就空；存储里的内容断电还在。保存就是把台面上的内容抄一份进存储。

@Highlight {
屏幕上看得见，不代表已经被抄进断电不丢的那一边。
}
}

@Card(id: "kc-files-card-name-vs-content", revision: 1, sourcePage: "kc-files-page-name", topic: "认识计算机", accent: "purple", frontTitle: "文件的两样东西", frontSubtitle: "改名之后内容还在吗", backTitle: "名字和内容") {
文件＝一个用来找它的名字 ＋ 一段内容，位置由系统另外记着。改名动的是标签。

@Highlight {
改一个几百兆文件的名字是瞬间完成的，因为内容根本没被重写。
}
}

@Card(id: "kc-files-card-convention", revision: 1, sourcePage: "kc-files-page-format", topic: "认识计算机", accent: "purple", frontTitle: "同一段内容两种读法", frontSubtitle: "后缀一改就成了乱码", backTitle: "靠约定还原") {
读出什么取决于用哪套约定去读。后缀只是提示系统该请谁来读，不决定内容是什么。

@Highlight {
乱码通常说明约定对不上，而不是内容坏了。
}
}
