@Tip(id: "kc-machine-tip-three-questions", revision: 1, sourcePage: "kc-machine-page-flow", title: "看不懂的功能先拆三段", systemImage: "lightbulb", accent: "purple") {
对任何一个功能问三句话：什么进去了，照什么步骤改的，什么出来了。三段填满，多半就不神秘了。
}

@Tip(id: "kc-machine-tip-no-guessing", revision: 1, sourcePage: "kc-machine-page-steps", title: "机器不猜，只照做", systemImage: "cpu", accent: "purple") {
遇到「它怎么不提醒我」，通常答案是没人写这一步，而不是机器偷懒。
}
