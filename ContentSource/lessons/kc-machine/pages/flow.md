你在记账 app 里敲下「12」，点一下「记一笔」，屏幕上的「本月合计」从 26 变成 38。这一下之间，机器到底做了什么？

它做了三件事：接住你按下的东西，照着一套事先写好的步骤算出新的合计，再把结果画到屏幕上。这三件事各有名字：输入、处理、输出。

## 一次点击，拆成三段

先把这次记账按发生的顺序摆出来。

```text
输入          处理                 输出
按下 12   →   26 ＋ 12 = 38   →   屏幕显示 38
```

顺序不能反。没有输入，处理没有可算的东西；没有输出，算完的 38 留在机器里，你根本不知道它算过。

## 输入不只是键盘，输出不只是屏幕

很多人以为输入就是打字、输出就是屏幕。其实这两个词只是在说方向：东西进入机器，还是离开机器。

- 你点的那一下、你拍的那张照片、麦克风听到的声音，都是输入。
- 外放的音乐、手机的震动、屏幕上的那个 38，都是输出。
- 从网上收到的一条消息是输入，你发出去的那条是输出。

@Callout(title: "看方向，不看长相", tone: "information", accent: "purple") {
同一样东西，进来的时候叫输入，出去的时候叫输出。判断依据是方向，不是它长什么样。
}

## 中间那一段最不透明

输入和输出你都看得见：手指按下去，数字亮起来。中间的「处理」你一眼看不到，它是这一课接下来要拆开的东西。

先拿一件小事练手：按下音量键之后，机器算出新的音量值，这一步属于三段中的哪一段？

@Quiz(id: "kc-machine-flow.quiz-1", kind: "singleChoice") {
你按了两下手机的音量减键，音乐声变小了。其中「机器根据你按的次数算出新的音量值」这一步，属于输入、处理还是输出？

@Option(id: "kc-machine-flow-q1-process", correct: true) {
处理

@Feedback(title: "它在改数据", tone: "success", accent: "mint") {
进入机器的是「被按了两下」这个信号；把它变成一个新的音量值，是照步骤在改数据。
}
}

@Option(id: "kc-machine-flow-q1-input") {
输入，因为这一步是你按键直接引起的
}

@Option(id: "kc-machine-flow-q1-output") {
输出，因为紧接着声音就变小了
}

@Feedback(when: "correct", title: "回答正确", tone: "success", accent: "mint") {
一步是不是处理，看它有没有把一份数据变成另一份数据，而不是看它离你按键有多近。
}

}
