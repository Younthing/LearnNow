有些事不能只放在浏览器：密码核验、权限判断、计费、防作弊。浏览器端代码用户看得见、改得了；**机密规则应放在服务器**。

```text
可放浏览器：即时字数提示
必须放服务器：最终是否允许发布、是否本人、是否超限
```

## 分工再钉一次

| 端 | 擅长 |
| --- | --- |
| 浏览器 | 展示与即时交互 |
| 服务器程序 | 共享逻辑、机密规则、持久入口 |

## 落到「小记」上

「是否管理员」「密码是否正确」若只写在浏览器，用户改几行脚本就能骗过界面。最终裁决必须在服务器。

## 再对照一次

| 适合浏览器 | 必须服务器 |
| --- | --- |
| 字数即时提示 | 是否允许删除 |
| 按钮加载中状态 | 密码核验 |
| 本地输入体验 | 防刷与限流 |

藏起按钮只影响老实人；直接发请求的人不受影响。

## 最终一句话

界面可以挡老实人；服务器规则才能挡请求。权限与机密，默认放远端。
