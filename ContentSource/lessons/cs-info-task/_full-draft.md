# Brief
- 核心问题：计算机如何完成一个任务？
- 心智模型：任务 = 输入 → 按清单处理 → 输出；换清单就换任务。
- 贯穿例子：手机计算器：按下 26 和 12，显示 38。
- 概念预算：核心=输入-处理-输出；支撑=程序(清单)、硬件执行；识别=软件；延后=编码、内存细节。

# 完整讲义

你打开手机计算器，按下 `26`、加号、`12`，屏幕跳出 `38`。计算机完成一个任务，靠的不是「懂你想算什么」，而是走完一条固定链条：**输入 → 处理 → 输出**。

按下的数字是输入，按加法规则算出结果是处理，屏幕上的 `38` 是输出。换一串按键，链条不变，结果会变。

```text
输入   按下 26 与 12
  ↓
处理   按加法清单算出 38
  ↓
输出   屏幕显示 38
```

真正决定「这一次算加法而不是乘法」的，是里面那份**步骤清单**。这份清单叫程序：人写好顺序，机器照着做。同一台手机，换一份清单，就能从记账变成放歌。

硬件负责执行。它不会猜你的意图：清单写加就加，写漏一步就漏一步。想换任务，改清单；想修错，也先改清单。

下一课会问：为什么输入输出都要先变成机器能存的形式。
