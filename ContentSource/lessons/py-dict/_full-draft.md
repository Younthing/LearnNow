# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 字典怎样通过名称查找数据？ |
| **心智模型** | 字典用键映射到值；按名字取，而不是按位置猜。 |
| **学习者起点** | 会列表。课内建立：键、值、查找。 |
| **终点行为** | 1. 能用键取出值。2. 能说明键应唯一。3. 能判断何时字典优于列表下标。 |
| **概念预算** | 核心：键值映射。支撑：取值、改值、键唯一。识别：keys。延后：嵌套字典。 |
| **贯穿例子** | {"语文":40, "数学":25} 各科分钟。 |
| **范围边界** | 会讲：按键查找。不讲：哈希原理、有序历史细节。 |

## 讲义

按「第几天」用下标可以；按「语文多少分钟」用下标就要记位置，易错。

字典用键（如科目名）映射到值。问名字，取到对应数据。
