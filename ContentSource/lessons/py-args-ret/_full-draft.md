# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 参数和返回值分别有什么作用？ |
| **心智模型** | 参数把数据送进函数；返回值把结果送回调用处。 |
| **学习者起点** | 会定义/调用。课内建立：参数、返回、副作用对比。 |
| **终点行为** | 1. 能说明参数是输入口。2. 能用 return 交出结果。3. 能区分 print 与 return。 |
| **概念预算** | 核心：进与出。支撑：参数、return、调用处接收。识别：多返回。延后：默认参数、*args。 |
| **贯穿例子** | is_done(minutes) 返回 True/False，调用处再决定打印。 |
| **范围边界** | 会讲：参数与返回。不讲：关键字参数细节、注解。 |

## 讲义

函数要处理不同分钟数，需要入口：参数。算完是否达标，若只 print，调用处拿不到结论再分支。

用 return 把结果送回。参数进、返回出；print 是给人看，return 是给程序下一站。
