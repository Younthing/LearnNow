# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 怎样遍历和处理一组数据？ |
| **心智模型** | 遍历时对每个元素做同一套处理：过滤、转换或汇总。 |
| **学习者起点** | 会 for 与容器。课内建立：遍历处理模式、累加、过滤。 |
| **终点行为** | 1. 能在循环中累加。2. 能过滤不符合的项。3. 能说明处理发生在每一轮。 |
| **概念预算** | 核心：遍历中处理。支撑：累加器、过滤、转换。识别：推导式。延后：map/filter 函数式。 |
| **贯穿例子** | 分钟列表：求和、只保留≥30、换成是否达标。 |
| **范围边界** | 会讲：循环内三类处理。不讲：生成器、并行。 |

## 讲义

有了列表，真正的工作常是：一边走一边处理——求和、丢掉无效、变成布尔。

遍历不是只 print；每一轮都可以更新汇总、决定是否收下、或写出转换后的新列表。
