「发布」按钮触发提交。按钮常以 `type="submit"` 放在表单里。按下后，浏览器把表单数据打成一次 HTTP 请求发给服务器（细节在服务器单元展开）。

## 提交是一次请求

```text
填写留言
  ↓
点提交
  ↓
浏览器发出请求（带表单数据）
  ↓
等待响应
```

## 本课边界

如何在服务器接收、如何校验、如何写入数据库，都是后面的课。这里只要会搭：`form` + 带 `name` 的控件 + 提交按钮。

## 和 HTTP 课接上

点「发布」后，浏览器通常发出一次带表单数据的请求，然后等待响应。这正是请求/响应对在表单场景下的样子。

## 本课收口

会搭：`form` + 带 `name` 的控件 + 提交按钮。接收、校验、入库是后面的服务器与数据库课。

还在浏览器的输入控件里。服务器不会因为你「正在输入」就自动知道内容——除非另做了自动保存，那是额外设计。
