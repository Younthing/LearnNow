# 完整讲义稿（存档，不编译）

## Brief（写作合同）

| 项 | 内容 |
|----|------|
| **核心问题** | 为什么要把代码写成函数？ |
| **心智模型** | 函数给一套步骤起名；调用名字就执行那套步骤。 |
| **学习者起点** | 会顺序与分支。课内建立：定义、调用、复用。 |
| **终点行为** | 1. 能说出函数是命名的步骤包。2. 能对比复制粘贴与调用。3. 能指出改一处等于改所有调用点的行为来源。 |
| **概念预算** | 核心：命名复用。支撑：def、调用、一处修改。识别：返回值（下节）。延后：参数细节。 |
| **贯穿例子** | print_status(minutes) 打印是否达标。 |
| **范围边界** | 会讲：为何函数、定义与调用。不讲：参数设计、作用域。 |

## 讲义

判断达标的几行代码在多处重复。改措辞要改很多处。

把这几行装进函数，起名，需要时调用。步骤集中在一处；行为来源变清晰。
