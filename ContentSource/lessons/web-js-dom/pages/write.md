读到之后，还可以**改**：改文字、改类别、显示/隐藏提示。例如把「还可写 20 字」写进某个 `span`。

```text
算出剩余字数
  ↓
找到提示用的元素
  ↓
改它的文字内容
```

## 改的是页面现状

这些修改发生在当前浏览器页面上。刷新后若没有额外保存，可能回到服务器原来送来的 HTML。要持久化，仍需后面的提交与存储。

## 落到「小记」上

算出剩余字数后，找到提示用的元素，改它的文字。用户立刻看见反馈，但还没有把留言存进数据库。

## 刷新之后呢

```text
JS 改当前页
  ↓
刷新
  ↓
通常回到服务器当初送来的 HTML
```

要让所有人长久看见，必须走提交与存储。DOM 修改默认是「这一次浏览里的变化」。

## 改类别也是一种改

除了改文字，还可以改元素的类别，从而让 CSS 接上另一套外观。读写的是节点，效果可以落到样式层。
