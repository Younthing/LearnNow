# Brief
- 核心问题：文字、图片和声音怎样变成二进制？
- 心智模型：比特是两种状态；不同媒介用不同映射表落到比特串；解码必须用对表。
- 贯穿例子：短信「到了」+ 一张小图 + 一声短提示音。
- 概念预算：核心=二进制表示；支撑=bit、映射表；识别=像素、采样；延后=压缩、UTF-8细节。

# 完整讲义

机器底层喜欢最省事的可区分状态：开/关，记成 `0` 与 `1`。一位这样的状态叫比特。文字、图片、声音表面不同，底层都可以变成一长串比特——差别在**映射规则**。

文字：每个字符对照码表变成数字，再写成比特。图片：画面切成像素，每个像素的颜色写成数。声音：按时间采样，振幅写成数。同一串比特，配错表就会读歪：把图当文字解，只会得到乱码或噪声式的误解。

记住：比特是原料；表决定它此刻代表字、色还是音。
