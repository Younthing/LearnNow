# Quality rubric — 教案评审清单

评审方式：逐条判定。每条给 `通过 / 重大缺陷 / 否决`。

- 出现任意一条 **否决**，或累计 ≥2 条 **重大缺陷** → 打回到完整稿（不允许只补一页）。
- 每条不通过的判定都必须写：具体位置（文件 + 页 ID）、为什么、以及一句可执行的改法。

---

## A. 否决项（任一命中即打回）

| # | 判据 | 命中的样子 |
|---|------|-----------|
| A1 | 表面模仿某一家 | 出现某频道口头禅、招牌开场、人格面具、中译标志句式；或读者能一眼说出"这在模仿谁"；或把写作指南的脚手架标题原样抄成页面小标题 |
| A2 | 事实错误或误导性简化 | 把"约定/解释"讲成"数据自带含义"，把 Unicode 说成"ASCII 的一种"，把 byte 说成"固定等于一个字符" |
| A3 | 依赖未教知识 | 题目或正文要求本课未铺垫的概念（零基础课出现"缓冲区""编码器"这类无铺垫术语） |
| A4 | 故事线断裂 | 去掉页码后读不出一条连贯讲义；或某页突然换了贯穿例子 |
| A5 | 违反格式硬约束 | 链接 / raw HTML / 引用块 / GFM 表格 / 嵌套列表 / 非法 `systemImage` / Quiz 缺反馈等 lint error |
| A6 | 答案有歧义 | 正确选项不唯一，或干扰项在某种合理解读下也成立 |
| A7 | 超过 3 页 | 单个 Lesson 的 `pages` 多于 3 项；或为了绕开页数把两个课题塞进同一个 Lesson |
| A8 | 单页超过 2 道题 | 某页出现 3 个及以上 `@Quiz` |
| A9 | 整页无结构 | 某页从头到尾没有 `##`，或只有连续段落、没有任何 fenced 块／列表／`@Callout` |
| A10 | 列表堆砌代替因果 | 本该讲机制的地方给出一串平铺列表，读者拿到条目却拿不到"为什么" |
| A11 | 概念预算爆表 | 核心概念多于 1 个，或必须掌握的支撑概念多于 4 个，或需要正式定义的术语多于 4 个 |
| A12 | 密密麻麻（wall of text） | 连续 3 段及以上普通段落之间没有任何 `##`／列表／fenced 块／`@Callout`；或某个 `##` 区块散文超过约 150 汉字却一个块都没有；或整页读起来像一篇文章而不是一屏一屏的教学页 |
| A13 | 单页超长 | 单页散文明显超过约 450 汉字（手机上超过 3 屏）。正确的改法是删、画、分、移到下一课，**不是**加页也不是留着 |

## B. 教学结构

| # | 判据 | 重大缺陷的样子 |
|---|------|----------------|
| B1 | 一页一概念簇 | 单页引入两个互不紧邻的新概念（bit ＋ Unicode），或一页里出现两次"其实" |
| B2 | 30 秒答案 | 页面开头 2～4 句没有给出该页的最小正确方向；或一上来就是历史、定义或例外 |
| B3 | 具体先于抽象 | 术语或定义出现在第一个实例之前 |
| B4 | 术语即时落地 | 术语首次出现的那句话没有给出它指的具体东西 |
| B5 | 挂接点 | 新概念出场前没有问题、旧经验或"没有它就出错"的现象在等它 |
| B6 | 层级完整 | 缺少动机开场，或缺少"命名与边界／变体与陷阱"就直接结束 |
| B7 | 每步可验证 | 页尾没有学习者能自己完成的判断动作 |
| B8 | 重复须升级 | 同一观点第二次出现只是换了说法，没有加机制、边界、反例或一次判断 |
| B9 | 收口与钩子 | 末页没有把全课钉在一句可迁移判断上；或钩子指向不存在的后续内容 |
| B10 | 主线测试 | 存在与核心问题只"间接相关"的区块，既没压成一句预告，也没移走 |

## C. 页面排版

| # | 判据 | 重大缺陷的样子 |
|---|------|----------------|
| C1 | `##` 分块 | 单页少于 2 个或多于 4 个 `##`；或标题说不出该节任务（"补充说明""其他"） |
| C2 | 标题层级 | 页内出现 `#`（课页标题已在 `lesson.yml`），或用到 `####` 及更深 |
| C3 | 至少一处可成像块 | 整页没有任何 fenced `text` 序列／对照，抽象关系只靠散文 |
| C4 | 对比的建立顺序 | 直接并排给两个对象的属性，事先没有各用一句话把它们建立起来 |
| C5 | 列表用对了 | 用无序列表承载过程或因果；或列表项之间并不同层级 |
| C6 | Callout 节制 | 一页 3 个及以上 `@Callout`；或 `@Callout` 读起来像术语摘要 |
| C7 | 段落粒度 | 出现 5 句以上不分段的长段，或一段超过约 90 汉字，或一段同时表达两个以上主要关系 |
| C8 | 断点密度 | 每约 150 汉字没有一个结构性断点（小标题／列表／fenced 块／`@Callout`）；或某个 `##` 下压着 4 段以上连续散文 |
| C9 | 该画的没画 | 用三段散文描述一条流程、一组对应关系或一个层次，而不是画进一个 fenced `text` 块 |
| C10 | 缺行内强调 | 整页几乎没有 `**bold**` 或 `` `code` ``，扫一眼抓不住任何钉子；关键判别点、对比轴、例子里的具体数字/标签全是灰字 |
| C11 | 行内强调过密 | 几乎每个名词都加粗（bold-every-noun）；或普通散文名词大量套 `` `code` ``（backtick soup）；或整句/整段包进 `**...**`；或单节粗体远超 3 处 |

## D. 认知负荷

| # | 判据 | 重大缺陷的样子 |
|---|------|----------------|
| D1 | 贯穿例子复用 | 为讲新概念另起一个无关例子 |
| D2 | 第一屏术语 | 页面第一屏出现 4 个及以上陌生术语 |
| D3 | 数字可心算 | 出现需要计算器的数字，或一次给出超过 4 个新数字 |
| D4 | 页长受控 | 单页散文超出约 250–450 汉字这个区间：偏长就删／画／移到下一课，偏短则 objective 没被真正教到 |
| D5 | 脑内可视化 | 抽象描述没有任何可成像的说法（无图时尤其重要） |
| D6 | 无冗余装饰 | 出现与理解无关的比喻、玩笑或情绪化修饰 |
| D7 | 比喻自带边界 | 用了比喻却没写"它不能解释什么"，或比喻替代了真实机制 |

## E. Quiz 质量

| # | 判据 | 重大缺陷的样子 |
|---|------|----------------|
| E1 | 考理解不考记忆 | 题目在问定义、数量、拼写等可查事实 |
| E2 | 情境化题干 | 题干是填空或"以下哪项正确" |
| E3 | 干扰项来自真实迷思 | 干扰项明显荒谬，或与正确项不在同一语义层 |
| E4 | 正确反馈有增量 | 正确反馈只说"回答正确"而不解释为什么 |
| E5 | 错误反馈定向 | 错误反馈没指名误解，或没给可执行的自检动作 |
| E6 | 答案未被剧透 | 答案已被同页 `@Callout` 或散文原句说完，题目退化成句子匹配 |
| E7 | 练习闭环 | 整课缺少主动回忆，或缺少一次区分／判断／迁移 |
| E8 | 合意困难 | 题目一眼可答（毫无思考），或需要跳步推理 |

## F. 复习产物

| # | 判据 | 重大缺陷的样子 |
|---|------|----------------|
| F1 | Card 只收判别点 | Card 背面复述整页散文，或收录不易忘的常识 |
| F2 | Card 可脱稿复述 | 背面正文长到无法在复习时一口气说完 |
| F3 | Highlight 是最易忘点 | `@Highlight` 与背面正文重复 |
| F4 | Tip 可独立成立 | Tip 脱离课程上下文后读不懂 |
| F5 | 覆盖与节制 | 关键判别点没有任何 Card 承载；或每页硬塞满 Card |

## G. 语言

| # | 判据 | 重大缺陷的样子 |
|---|------|----------------|
| G1 | 成年人口语 | 卖萌、堆梗、感叹号催情绪 |
| G2 | 无学术腔 | "综上所述""本节旨在" |

## 评审输出格式

```text
结论: 通过 / 打回
否决项: A? — 位置 — 原因 — 改法
重大缺陷: B?/C?/D?/E?/F?/G? — 位置 — 原因 — 改法
建议（非阻塞）: ...
```

打回时必须说明**改哪一段完整稿**，而不是改哪一页 Markdown。

## 眯眼测试（排版第一关，先做这个）

不读内容，只看形状：把页面缩到看不清字，看它是不是一大片均匀的灰色。

- 一屏之内看不到任何标题、列表、fenced 块或 `@Callout` → 命中 **A12**。
- 段落长度肉眼可见地都差不多长、都很长 → 段落没在 2～4 句的范围里，命中 **C7**。
- 全页只有两三个断点、其余全是灰块 → 命中 **C8**。

再略放大到能辨认加粗与等宽字：

- 整页看不到任何粗体或行内 code 锚点，关键数字/判别点全是灰字 → 命中 **C10**。
- 粗体或反引号密到像涂鸦 → 命中 **C11**。

眯眼测试不通过就不用往下读了，先按 `references/pedagogy.md` § 拆墙的正确动作
（删 → 画 → 分 → 移）改完再评审；缺行内强调则按 § 行内强调补稀疏锚点。

## 五遍修改法（评审前自查顺序）

一遍只看一件事，混着看会两件都漏：

1. **范围**：本课只回答哪个问题？哪些段落属于下一课？删掉哪些后主模型仍完整？
2. **认知顺序**：每个概念出现前有挂接点吗？先例子后定义吗？有需要后文才懂的句子吗？
3. **准确性**：哪些句子是教学简化？它在什么条件下成立？有没有把常见写成绝对？
4. **表达负担**：哪些句子同时表达两个关系？哪些列表该改成两句话？哪些重复没增值？
5. **学习结果**：能复述主模型吗？练习真的需要理解吗？能用到新情境吗？下一步唯一吗？
